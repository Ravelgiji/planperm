# Dedicated Pin Tool Verification

The map now exposes a distinct **Draw a marker** control for choosing a site. It displays a short placement instruction and can be cancelled without changing the active planning context. A deliberate placement at `53.27774, -9.07059` updated the selected site and refreshed the nearby application total from 220 to 226.

Normal navigation remains available outside this explicit selection tool: map dragging and scroll-wheel zoom are enabled, while double-click zoom is disabled. This removes the prior conflict where an ordinary map click could accidentally change the selected site or be interpreted as navigation.
